## Tech Stack

- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Database**: PostgreSQL with Prisma ORM v7
- **Animation**: Framer Motion

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- PostgreSQL (installed and running)

### Installation

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Set up environment variables**
   
   Create or update the `.env` file with your PostgreSQL credentials:
   ```env
   DATABASE_URL="postgresql://username:password@localhost:5432/bnt_db?schema=public"
   ```

3. **Set up the database**
   
   Generate Prisma Client:
   ```bash
   npm run prisma:generate
   ```
   
   Run migrations to create database tables:
   ```bash
   npm run prisma:migrate
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```

## Database Commands

- `npm run prisma:generate` - Generate Prisma Client from schema
- `npm run prisma:migrate` - Create and apply database migrations
- `npm run prisma:studio` - Open Prisma Studio (visual database editor)
- `npm run prisma:push` - Push schema changes without creating migrations
- `npm run prisma:seed` - Seed database with sample data

## Database Models

The application uses the following database models:

- **Story** - Community stories and testimonials
- **ImpactMetric** - Impact statistics (books distributed, children reached, etc.)
- **GalleryItem** - Photo gallery with event associations
- **CommunityMember** - Volunteers and team members
- **Event** - Community events and activities

For detailed schema documentation, see [prisma/README.md](prisma/README.md).

## Development

### Using the Database

Import the Prisma client or utility functions:

```typescript
import { prisma } from '@/lib/prisma';
// or
import { getPublishedStories, getActiveImpactMetrics } from '@/lib/db';
```

Example queries:

```typescript
// Get published stories
const stories = await getPublishedStories();

// Get active impact metrics
const metrics = await getActiveImpactMetrics();

// Get upcoming events
const events = await getUpcomingEvents();
```
